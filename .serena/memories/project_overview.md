Argus Renewal is a Korean-first financial news app. Stack: Next.js App Router frontend, FastAPI backend, SQLite with SQL migrations, TypeScript and Python. KRX market news now materializes from raw_documents into market-surface tables news_batch_triage, market_surface_candidates, market_surface_state, and market_surface_history. Key validation commands: `cd backend && pytest -q`, `cd backend && python3 -m py_compile src/krx/news/service.py`, `cd frontend && pnpm vitest run src/app/krx/news/page.test.tsx`.
