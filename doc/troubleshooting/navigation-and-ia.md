# Navigation And IA

## 왜 이 작업이 필요했나
기존 화면은 내용은 많았지만, 처음 보는 사람이 어디서 무엇을 봐야 하는지 직관적이지 않았습니다. 특히 `종합`, `중요 정보`, `글로벌 이벤트` 같은 이름은 실제 화면 역할과 완전히 일치하지 않았습니다.

## 왜 이렇게 처리했나
사용자 흐름을 기준으로 상단 탭을 다시 정리했습니다.

- `대시보드`: 오늘 장의 전체 요약을 가장 먼저 보는 곳
- `AI 인사이트`: AI가 해석한 방향과 분위기를 보는 곳
- `파생·수급`: 누가 어떤 방향으로 베팅하는지 보는 곳
- `시장 뉴스`: 기사와 공시를 보는 곳
- `매크로 캘린더`: 해외 일정과 촉매를 보는 곳

이렇게 나누면 사용자가 `오늘 시장이 어떤가 -> AI는 어떻게 보나 -> 실제 숫자는 어떤가 -> 이유는 뭔가` 순서로 자연스럽게 따라갈 수 있습니다.

## 왜 이름만 바꾸지 않았나
이름만 바꾸면 더 헷갈릴 수 있기 때문입니다. 예를 들어 `AI 인사이트`라고 써놓고 실제 내용이 단순 참고 카드만 있으면 사용자는 금방 혼란을 느낍니다. 그래서 `오늘의 시장 톤` 같은 해석 콘텐츠를 실제로 `AI 인사이트` 탭 중심으로 옮긴 뒤 이름을 맞췄습니다.

## 이상할 때 체크할 것
- 상단 GNB가 `대시보드 / AI 인사이트 / 파생·수급 / 시장 뉴스 / 매크로 캘린더` 순서인지 확인합니다.
- 공통 헤더가 예전처럼 큰 해석 블록을 들고 있지 않은지 확인합니다.
- `AI 인사이트` 탭에 `오늘의 시장 톤`이 보이는지 확인합니다.
