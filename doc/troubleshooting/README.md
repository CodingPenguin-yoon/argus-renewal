# Troubleshooting Guide

`troubleshooting/`은 오늘 바뀐 내용을 비전공자도 이해할 수 있게 설명하는 문서 묶음입니다.

## 읽는 순서
1. `navigation-and-ia.md`
2. `performance-and-prefetch.md`
3. `dashboard-and-insights.md`
4. `routing-and-links.md`
5. `docs-and-history.md`

## 문서 역할
- `navigation-and-ia.md`
  - 왜 탭 구조를 바꿨는지 설명합니다.
- `performance-and-prefetch.md`
  - 왜 캐시와 prefetch를 탭별로 다르게 적용했는지 설명합니다.
- `dashboard-and-insights.md`
  - 대시보드 위젯과 AI 인사이트 게이지를 왜 넣었는지 설명합니다.
- `routing-and-links.md`
  - 왜 주소를 새 이름에 맞게 바꾸고, 옛 주소는 redirect로 남겼는지 설명합니다.
- `docs-and-history.md`
  - 왜 문서를 다시 나누고, 어떤 문서를 봐야 하는지 설명합니다.
